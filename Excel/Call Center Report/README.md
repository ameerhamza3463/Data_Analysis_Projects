# 📊 Call Center Performance Dashboard

This project is a dynamic and interactive Excel-based dashboard developed to analyze key metrics from a call center's operations. The dashboard offers clear and concise visualizations, enabling quick insights and data-driven decision-making for business performance enhancement.

## 📁 Project Overview

The dashboard compiles raw call center data and transforms it into meaningful summaries and visual reports. It focuses on metrics such as:
- Total Calls Received
- Average Call Duration
- Agent-wise Performance
- Customer Satisfaction Scores

## 💡 Objective

To empower call center managers and analysts with a comprehensive view of operational efficiency, identify performance bottlenecks, and enable strategic planning through data-driven insights.

## 🔧 Techniques and Tools Used

| Category                | Techniques/Features Applied                                   |
|------------------------|---------------------------------------------------------------|
| 📌 Data Analysis        | Pivot Tables, Formulas (`IF`, `SUMIFS`, `COUNTIFS`, etc.)     |
| 🔄 Data Modeling        | Data Relationships, Data Model integration                    |
| 🎨 Visualization        | Charts (Bar, Line, Combo), KPIs, Conditional Formatting        |
| 🧠 Interactivity        | Slicers, Dynamic Chart Titles, Interactive Filters            |
| 🖌️ Custom Design        | Clean layout, color themes, and logical data arrangement       |

## 📈 Key Features

- Interactive slicers for filtering by date, region, or agent
- Highlighted KPIs with conditional formatting for performance monitoring
- Trend and comparative visualizations to understand changes over time
- Custom layout optimized for clarity and ease of use

## 🚀 How to Use

1. Open the `Call Center Report.xlsx` file in Microsoft Excel (2016 or newer recommended).
2. Use slicers to filter reports based on time period, agent, or call status.
3. Review key metrics and charts to gather insights.

## 🏁 Outcome

This dashboard enhances visibility into the call center’s operations, supporting better decision-making and proactive management of service quality.
